# منصة حاضر

منصة تشغيلية واحدة لمدرب الكلية التقنية ببيشة، تجمع ثلاث خدمات:

| الخدمة | ما تفعله |
|---|---|
| **تحضير المتدربين** | تحضير يومي للشعب النظرية والعملية، نسب الغياب والإنذار المبكر، ومزامنة التحضير مع منصة رايات (Banner) عبر جسر يعمل في متصفح المدرب نفسه |
| **الإرشاد والسلوك** | سجل المخالفات والحالات، مهام المرشد وإشعاراته، ونماذج الإنذار |
| **إدارة الاختبارات ورصد الدرجات** | توزيع الدرجات مستورداً من ملف الكلية، إدخال الدرجات والتحقق منها، التجميد الأكاديمي والاعتماد، جدولة الرفع، ورفع الدرجات إلى رايات مع المطابقة العكسية |
| **حسابات المتدربين** | اسم المستخدم هو الرقم التدريبي (ثابت لا يُعدَّل)، وكلمة مرور مؤقتة مشفّرة، ومصنفات التسليم |

## البنية

المنصة **صفحة واحدة** (`index.html`) تعمل داخل Claude Artifacts وتستخدم قاعدة بياناته (`claude.use('db')`) للتخزين. لا خادم ولا بناء (build) لازم للتشغيل: تُفتح الصفحة فتعمل.

```
index.html              الصفحة المبنية الجاهزة للنشر (مولّدة، لا تُحرَّر يدوياً)
base/haader-v20.html    الأساس: التحضير والإرشاد
src/grades/             وحدات قسم الدرجات وحسابات المتدربين ونظام النوافذ
  g1-engine.js          محرّك التحقق والحالات والبصمات (بلا DOM)
  g2-data.js            المجموعات والصلاحيات وسجل التدقيق
  g3a/g3b/g3c-views.js  الواجهات العشر
  g4-actions.js         الاستيراد والتصدير وكل الإجراءات
  g5-accounts.js        حسابات المتدربين وكلمات المرور والمصنفات
  g0-ui.js              نظام النوافذ الموحد (sm / md / wide / side)
  modal.css grades.css  الأنماط
src/bridge/             «جسر حاضر»: يقرأ ويكتب في رايات من تبويب المدرب
tools/build.py          يولّد index.html من الأساس + الوحدات + الجسر
tests/                  اختبارات Playwright: 129 + 42 + 14 + لقطات التجاوب
```

## البناء

```bash
python3 tools/build.py      # يكتب out/index.html ويفحص السكربتات نحوياً
node tests/run.js           # 129 اختباراً لقسم الدرجات
node tests/acc.js           # 42 اختباراً لحسابات المتدربين
```

## أمن البيانات

- كلمات مرور المتدربين تُحفظ **بصمةً** (PBKDF2-SHA256، ملح عشوائي، 150 ألف دورة)، ولا تُخزَّن نصاً ولا تظهر في سجل التدقيق.
- المصنف المتداول بين المدربين لا يحتوي كلمات مرور: اسم المتدرب ورقمه التدريبي واسم المستخدم وحالة التسليم فقط.
- سجل التدقيق محمي على مستوى القاعدة: لكل مستخدم وثيقته، ولا يكتب فيها غيره.
- الشعبة لمدربها: الإدخال والاعتماد والجدولة والرفع لمدرب المقرر وحده، ورئيس القسم للاطلاع والمتابعة.
- **ليس في هذا المستودع أي بيانات متدربين حقيقية.** ملفات الاختبار بأسماء وأرقام مصطنعة، وملفات الكلية الفعلية مستثناة في `.gitignore`.

## ما لا تفعله المنصة بعد

- **دخول المتدربين لا يعمل على رابط Claude**، ويعمل على الرابط المنشور (انظر «نسخة الويب»).
- لا يوجد خادم، فجدولة الرفع تُجمّد نسخة وتُنبّه في موعدها، أما التنفيذ فيبقى بجلسة المدرب في رايات.
- لا يوجد واجهة رسمية (API) للمدرب في رايات، فالكتابة تمر عبر جسر يعمل في متصفحه، بتأكيد صريح، وللقيم المتغيرة وحدها، ثم يُعاد القراءة للتحقق.

## نسخة الويب (الرابط المنشور)

الرابط: https://3bdr7man.github.io/haader/ — يُنشر من مجلد `docs/` في الفرع `main`.

```
src/web/shim.js     طبقة الاتصال بالخادم (Supabase): الجلسة والتجديد والوثائق بالواجهة نفسها التي تتوقعها المنصة
src/web/post.js     شاشة الدخول الموحدة، والخروج، وتغيير كلمة المرور، ونقل البيانات من نسخة Claude، وتنبيه التحديث
src/web/portal.js   بوابة المتدرب، والتحضير المباشر بمسح رمز QR
src/web/web.css     أنماطها
tools/build_web.py  يبني docs/index.html من index.html + الملفات أعلاه
supabase/04_auth.sql الدخول الموحد والصلاحيات على مستوى القاعدة وبوابة المتدرب وQR المباشر
tests/stack/        اختبارات على خادم محلي حقيقي (Postgres + GoTrue + PostgREST) وفي متصفح Chromium
```

- **الدخول**: شاشة واحدة. المدرب ورئيس القسم والمسؤول باسم المستخدم، والمتدرب برقمه التدريبي. يطلب المتصفح الملح من الخادم، ويحسب بصمة PBKDF2 لكلمة المرور، ويدخل بها إلى Supabase Auth. كلمة المرور لا تغادر المتصفح، والبصمة لا تُقرأ من القاعدة.
- **الحسابات**: كل حساب ينشئه المسؤول أو المدرب في المنصة يصبح حساب دخول تلقائياً (زناد في القاعدة)، والتعطيل يمنع الدخول وينهي الجلسات. التسجيل الذاتي مغلق.
- **الصلاحيات على الخادم** (سياسات RLS على جدول `doc`): المدرب يقرأ ويكتب شعبه وحدها، ورئيس القسم والاطلاع يقرآن الكل ولا يحضّران، ولا يغيّر أحد دوره أو مدرب الشعبة إلا المسؤول، ولا تُحذف المخالفات والسجلات.
- **المتدرب**: لا يقرأ جدول الوثائق إطلاقاً؛ يرى بياناته وحده عبر الدالة `trainee_me`، ويحضّر عبر `qr_checkin` التي تتحقق من التوقيع والوقت والتسجيل في الشعبة وعدم التكرار.

```bash
python3 tools/build_web.py           # يبني docs/
node tests/stack/auth.test.js        # 93 اختباراً للخادم (يتطلب الخادم المحلي)
node tests/stack/e2e.test.js         # 43 اختباراً في المتصفح
```
